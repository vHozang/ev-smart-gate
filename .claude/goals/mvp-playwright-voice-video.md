# GOAL — MVP Playwright Voice Video Workflow

## USER_OBJECTIVE

Create a repeatable one-command workflow that demonstrates the EV Smart Gate MVP through the real UI, records it with Playwright, generates professional Vietnamese OpenAI TTS narration and SRT subtitles, assembles H.264/AAC videos with FFmpeg, and finishes only after `dist/demo/MVP-Demo.mp4` is generated and verified.

## SELECTED_PLAN

1. Add a root npm toolchain using `@playwright/test`, `openai`, and `dotenv`.
2. Add a Chromium-only `mvp-demo` Playwright project with 1440x900 viewport/video and complete artifacts.
3. Exercise the real application at `http://localhost:8000` against Docker Compose services with simulated AI.
4. Demonstrate the full critical flow: open app, log in, dashboard, prepare driver/vehicle/authorization, Gate In, create order, inspect cargo, issue signed Exit Slip, Gate Out, verify `COMPLETED`.
5. Use semantic locators, `test.step`, assertions, and generate `timeline.json`.
6. Generate per-segment Vietnamese TTS with `gpt-4o-mini-tts`, voice `marin`; never fake audio.
7. Generate SRT from the timeline, synchronize narration with FFmpeg, produce voice-only and subtitle-burned MP4 files.
8. Make `npm run demo:mvp` orchestrate and fail fast across the complete pipeline and verify outputs with `ffprobe`.
9. Add a dedicated CI E2E job without slowing the existing Python suite.
10. Do not commit or push.
