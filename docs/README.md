# Tài liệu EV Smart Gate

- `BRD.md`: mục tiêu, vai trò, quy tắc và tiêu chí nghiệm thu.
- `smart-gate-system-design.md`: HLD, luồng dữ liệu, bảo mật và failure mode.
- `data-model-erd.md`: collection MongoDB, quan hệ logic và indexes.
- `diagrams.md`: Mermaid source của component/workflow/deployment.
- `project-structure.md`: cấu trúc Clean Architecture và dependency rule.
- `development.md`: thiết lập local, test, model và vận hành.
- `frontend-architecture.md`: kiến trúc SPA, phân quyền, session/CSRF và WebSocket.
- `requirements-traceability.md`: ánh xạ yêu cầu -> code -> test.
- `clean-architecture-fastapi-smart-gate-prompt.md`: prompt tái tạo/đánh giá dự án.

`diagrams.html` là artifact người dùng quản lý riêng và không được generator này ghi đè.
