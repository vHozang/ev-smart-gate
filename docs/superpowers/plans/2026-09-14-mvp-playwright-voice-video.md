# MVP Playwright Voice Video Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reproducible `npm run demo:mvp` pipeline that drives the real EV Smart Gate MVP, narrates it in Vietnamese, burns synchronized subtitles, and verifies `dist/demo/MVP-Demo.mp4`.

**Architecture:** Playwright Test runs a dedicated Chromium project against the Docker Compose application and writes an explicit business-step timeline plus a uniquely scoped raw browser video. Focused Node ESM modules validate environment, generate per-step OpenAI TTS and SRT files, assemble media with FFmpeg, and verify streams with ffprobe; a fail-fast orchestrator owns the complete lifecycle.

**Tech Stack:** Node.js 26/npm, TypeScript Playwright Test, OpenAI Node SDK (`gpt-4o-mini-tts`, `marin`), dotenv, Docker Compose/FastAPI/MongoDB/MinIO, FFmpeg/ffprobe, GitHub Actions.

**Spec:** `.claude/goals/mvp-playwright-voice-video.md` (authoritative goal), sourced from `C:\Users\vHozang\Downloads\MVP_PLAYWRIGHT_VOICE_VIDEO_WORKFLOW.md`

## Global Constraints

- Keep the same-origin FastAPI-served vanilla JavaScript SPA unchanged except for accessibility fixes required for semantic automation.
- Use the real local Docker Compose stack with simulated AI; do not mock APIs or build a fake page.
- Use Chromium only, viewport and recorded video size `1440x900`.
- Record video, trace, screenshots on failure, and an HTML report for the dedicated demo project.
- Generate Vietnamese narration with OpenAI model `gpt-4o-mini-tts`, default voice `marin`; never synthesize fake fallback audio.
- Use timeline-derived timestamps for audio delays and SRT cues; never hardcode synchronization offsets in FFmpeg assembly.
- Output H.264/yuv420p video and AAC audio; verify existence, positive size/duration, streams, codecs, and resolution with ffprobe.
- Never expose passwords, API keys, tokens, or private data in narration, subtitles, tracked logs, or visible video.
- Never commit or push during this task.
